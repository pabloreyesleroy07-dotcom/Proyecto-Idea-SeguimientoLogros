# Proyecto-Idea-SeguimientoLogros
Idea del proyecto web que se desarrollara en el modulo 'Proyecto'. Esta es una idea inical sobre un posible proyecto, este podria ser descartado o recibir cambios en un futuro.  
## ¿Como lo haremos?
En este proyecto se utilizara MERN Stack, se trata de tecnologías basadas en JavaScript utilizadas para el desarrollo web.  
Para entender que significa MERN Stack te recomendaria que visites [esta pagina](https://www.mongodb.com/es/resources/languages/mern-stack).
